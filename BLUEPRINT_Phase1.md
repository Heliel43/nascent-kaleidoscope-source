### 3. LITRPG SYSTEM MECHANICS (Defined from Resources)

**Core System Source:** `A_Gamers_Grand_Journey.txt` + `Game of Monsters (DxD - Gamer).txt` + `The Guild of Gamers The Supervillain.txt`

**System: The Gamer (Grounded Variant)**

**Stats:**
- HP: 100 + (VIT*20 + Level*10)
- MP: 100 + (MAG*15 + INT*10)
- SP: 100 + (END*15 + STR*5)
- VIT, STR, DEX, END, INT, WIS, MAG, LUK, CHA - Base 10, growth per level + stat points.

**Race: Human (Pragmatic)**
Vit x2, STR x4, DEX x3, END x4, INT x3, WIS x3, MAG x2, LUK x2, CHA x1 (from A_Gamers_Grand_Journey)

**Core Perks (Permanent):**
- [Gamer's Mind] - Immunity to high-level mental effects, calm in crisis, logical thinking.
- [Gamer's Body] - Live like game, full restore on sleep, injuries become HP loss.
- [Regeneration] - HP = VIT x4 per min, MP = MAG x3, SP = END x2
- [Muscle Memory] (unlocked after first kill) - body remembers combat.

**Skills:**
- [Observe LVL 1-100] - Info on targets. Level via use. Starts vague, becomes detailed.
- [ID Create / Escape] - Creates pocket dimension with respawning mobs for safe training. Crucial for slow, logical grinding without breaking world economy. Cost 0 MP.
- Skill Books: Learn via doing + manuals (from Borne_of_Caution, Ghost_in_the_City).

**Progression Rules (Royal Road Grounded):**
- No instant godhood. Levels give 5 stat points. Skills level via use (1-100). Must train.
- Dungeons give EXP but with diminishing returns if farmed same day.
- No free legendary gacha at start (we delay the Token from A_Gamers_Grand_Journey to Arc 3 as earned reward).
- Quests are System-generated but pragmatic: "Survive", "Find Shelter", "Unlock Mana" - not "Kill God".

**Economy:**
Credits/Lien converted to Gold/Silver/Copper. Inventory has weight limit.
